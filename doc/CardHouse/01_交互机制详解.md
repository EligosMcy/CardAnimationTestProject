## 1. 整体架构

CardHouse 的交互系统采用 **物理驱动 + 事件驱动** 的混合架构，核心设计如下：

```
┌─────────────────────────────────────────────────────────────────┐
│                     Card（卡牌实体）                            │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  Seek 动画系统（位置/旋转/缩放）                        │   │
│  │  Homing / Turning / Scaling (BaseSeekerComponent<T>)     │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  交互检测器（继承 Toggleable）                          │   │
│  │  ├── DragDetector  (OnMouseDown → OnDragStart)          │   │
│  │  ├── ClickDetector (OnMouseDown/UpAsButton)             │   │
│  │  └── HoverDetector (OnMouseEnter/Exit)                  │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  行为策略                                               │   │
│  │  └── DragOperator → 定义 DragAction                     │   │
│  └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                   CardGroup（卡牌分组容器）                      │
│                                                                 │
│  ├── MountedCards : List<Card>       ← 挂载的卡牌有序列表      │
│  ├── CardGroupSettings (布局策略)    ← 卡牌摆放在哪里          │
│  ├── DropGates (合法性门控)          ← 拖拽是否允许放下        │
│  └── TriggerEnterRelay (辅助碰撞)   ← 扩展碰撞区域            │
│                                                                 │
│  静态成员：                                                     │
│  ├── GroupsHoveredWithObjects : Stack ← 鼠标悬停 Group 栈     │
│  └── HilightedGroup : CardGroup      ← 当前高亮 Group         │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│              Dragging（拖拽引擎单例）                           │
│                                                                 │
│  职责：监听拖拽事件，每帧将卡牌平滑追踪到鼠标位置                │
│  事件：OnDrag / OnDrop / PostDrop                               │
└─────────────────────────────────────────────────────────────────┘
```

### 核心设计理念

1. **基于 3D 物理碰撞**：使用 `OnMouseDown/Enter/Exit` 和 `OnTriggerEnter2D/Exit2D`，绕过 Unity UI 的 EventSystem
2. **Seek 动画分离**：交互触发位置/旋转/缩放变化，但具体"怎么动"由 Seeker 策略决定
3. **Gate 门控系统**：所有关键操作都经过 Gate 合法性校验，规则可插拔
4. **静态事件广播**：`Dragging.OnDrag`、`CardGroup.OnGroupChanged` 等静态事件，实现松耦合通信

## 2. 基础组件 Toggleable

**源码**：[Toggleable.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Toggleable.cs)

```csharp
public class Toggleable : MonoBehaviour
{
    public bool IsActive = true;
    public void SetIsActive(bool newValue) { IsActive = newValue; }
}
```

所有交互检测器（`DragDetector`、`HoverDetector`、`ClickDetector`）都继承自 `Toggleable`。这意味着：

- 每张卡的交互可以**独立开关**
- 可以通过 Group/Phase 批量启用/禁用某类交互
- `Gate` 也继承自 `Toggleable`，未激活的 Gate 视为"已解锁"

## 3. 拖拽交互机制

拖拽是 CardHouse 最核心的交互，由三层组件协同完成。

### 3.1 DragDetector — 拖拽事件源

**源码**：[DragDetector.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Dragging/DragDetector.cs)

```csharp
public class DragDetector : Toggleable
{
    public GateCollection<NoParams> DragGates;           // 拖拽启动门控
    public GateCollection<DropParams> GroupDropGates;   // 目标 Group 放下门控
    public GateCollection<TargetCardParams> TargetCardGates; // 目标卡选择门控
    public UnityEvent OnDragStart;   // 按下时触发
    public UnityEvent OnDragEnd;     // 松开时触发

    void OnMouseDown()
    {
        if (!IsActive || !DragGates.AllUnlocked(null))
            return;
        OnDragStart.Invoke();
    }

    void OnMouseUp()
    {
        if (!IsActive || !DragGates.AllUnlocked(null))
            return;
        OnDragEnd.Invoke();
    }
}
```

**工作流程**：

1. Unity 物理系统检测到鼠标在卡牌 Collider2D 上按下
2. `OnMouseDown` 检查自身是否激活 + `DragGates` 是否全部通过
3. 校验通过 → 触发 `OnDragStart` 事件
4. 鼠标松开时同理触发 `OnDragEnd`

### 3.2 Dragging 单例 — 拖拽引擎

**源码**：[Dragging.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Dragging/Dragging.cs)

`Dragging` 是全局单例，负责拖拽期间的位置追踪和事件广播：

```csharp
public class Dragging : MonoBehaviour
{
    public static Dragging Instance;
    public Action<DragDetector> OnDrag;      // 拖拽开始广播
    public Action<DragDetector> OnDrop;      // 放下广播
    public Action<DragDetector> PostDrop;    // 放下后广播（收尾）

    DragDetector TargetDraggable;
    Homing TargetHoming;
    Turning TargetTurning;
    bool IsDragging;

    void Update()
    {
        if (!IsDragging) return;
        GoToMouse(StartingZ - CardPopupDistance);  // Z轴向前推，确保在最前层
    }

    void GoToMouse(float newZ)
    {
        var mouseWorldPosition = Camera.main.ScreenToWorldPoint(Input.mousePosition);
        if (UseGrabOffset) mouseWorldPosition += GrabOffset;

        // Z轴修正：忽略鼠标实际深度，保持卡牌在固定 Z 平面
        var zCorrection = Vector3.back * (mouseWorldPosition.z - newZ);
        TargetHoming.StartSeeking(mouseWorldPosition + zCorrection, MyStrategy);
    }
}
```

**关键设计点**：

| 设计 | 说明 |
|------|------|
| `ScreenToWorldPoint` | 将屏幕坐标转为世界坐标，支持 3D 空间拖拽 |
| `zCorrection` | 修正鼠标 Z 深度，卡牌始终保持在期望 Z 平面 |
| `CardPopupDistance` | 拖拽时卡牌 Z 前移，避免被其他卡遮挡 |
| `GrabOffset` | 抓取时记录偏移量，卡牌不会"跳手" |
| `Seeker 策略` | 拖拽不硬跟随，而是通过 Seeker 平滑追踪 |

### 3.3 DragOperator — 拖拽行为策略

**源码**：[DragOperator.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Dragging/DragOperator.cs)

`DragOperator` 是挂在卡牌上的"拖拽行为配置器"，定义了松手后卡牌的处理方式：

```csharp
public class DragOperator : MonoBehaviour
{
    public DragDetector MyDragDetector;
    public DragAction DragAction;       // Mount / UseAndDiscard / UseOnTargetAndDiscard
    public float DragSwell = 1.2f;      // 拖拽时放大倍数
    public bool PointUpWhenDragged = true;  // 拖拽时是否朝向镜头
    public SeekerScriptableSet PresentationSeekers;  // 展示动画策略

    public void SetDragState(bool newState)
    {
        if (newState)
        {
            if (UseDragSwell) MyScaling.StartSeeking(DragSwell);
            Dragging.Instance.BeginDragging(MyDragDetector, MyHoming, MyTurning, PointUpWhenDragged);
        }
        else
        {
            if (UseDragSwell) MyScaling.StartSeeking(1f);
            Dragging.Instance.StopDragging();
        }
    }
}
```

**DragAction 枚举**（决定放下后的处理逻辑）：

```csharp
public enum DragAction
{
    None,                    // 无操作
    Mount,                   // 挂载到目标 Group（如手牌→卡组）
    UseAndDiscard,           // 使用后弃牌
    UseOnTargetAndDiscard    // 对目标卡使用后弃牌
}
```

### 3.4 完整拖拽生命周期

```
鼠标按下
  │
  ▼
┌──────────────────────────────────────┐
│  DragDetector.OnMouseDown()          │
│  检查 IsActive + DragGates           │
│  → 触发 OnDragStart                  │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│  DragOperator.SetDragState(true)     │
│  ├── Scaling → DragSwell（放大）     │
│  └── Dragging.BeginDragging()        │
│      ├── 记录目标 Homing/Turning     │
│      ├── Turning 朝向镜头            │
│      └── IsDragging = true           │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│  Dragging.Update() 每帧              │
│  ├── ScreenToWorldPoint(mouse)       │
│  ├── Z 轴修正                        │
│  └── TargetHoming.StartSeeking(...)  │
│      → Seeker 平滑追踪鼠标           │
└──────────────┬───────────────────────┘
               │
               ▼  鼠标松开
┌──────────────────────────────────────┐
│  DragDetector.OnMouseUp()             │
│  检查 IsActive + DragGates           │
│  → 触发 OnDragEnd                    │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│  Dragging.StopDragging()              │
│  ├── IsDragging = false              │
│  ├── GoToMouse(StartingZ)            │
│  ├── OnDrop 广播 → CardGroup 处理放下│
│  └── PostDrop 广播 → 清理高亮        │
└──────────────────────────────────────┘
```

## 4. 点击交互机制

**源码**：[ClickDetector.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Click/ClickDetector.cs)

```csharp
public class ClickDetector : Toggleable
{
    public UnityEvent OnPress;          // 鼠标按下即刻触发
    public UnityEvent OnButtonClicked;  // 鼠标在同位置松开触发（完成点击）
    public GateCollection<NoParams> ClickGates;

    void OnMouseDown()
    {
        if (IsActive && ClickGates.AllUnlocked(null))
            OnPress.Invoke();
    }

    void OnMouseUpAsButton()
    {
        if (IsActive && ClickGates.AllUnlocked(null))
            OnButtonClicked.Invoke();
    }
}
```

**设计特点**：

- 区分"按下"和"完成点击"两个事件，类似 Unity UI 的 `IPointerDownHandler` + `IPointerClickHandler`
- `OnMouseUpAsButton` 只在鼠标在同一 Collider 上松开时触发，移动到其他物体或松开则不触发
- 同样受 `ClickGates` 门控，可实现"只有特定阶段/条件下才能点击"

## 5. Hover 交互机制

**源码**：[HoverDetector.cs](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Hover/HoverDetector.cs)

```csharp
public class HoverDetector : Toggleable
{
    public UnityEvent OnHover;     // 鼠标进入时触发
    public UnityEvent OnUnHover;   // 鼠标离开时触发

    void OnMouseEnter()
    {
        if (!IsActive) return;
        OnHover.Invoke();
    }

    void OnMouseExit()
    {
        if (!IsActive) return;
        OnUnHover.Invoke();
    }
}
```

`HoverDetector` 是一个纯事件分发器，它本身不做任何视觉处理。典型用法是在 Inspector 中绑定 UnityEvent：

```
HoverDetector.OnHover → Card.SetFocus(true)    // 聚焦放大
                       → Homing.StartSeeking(...) // 推前
                       → Scaling.StartSeeking(...) // 放大
```

此外，`Card.SetFocus` 提供了更高级的聚焦模式：

```csharp
// Card.cs#L124-L147
public void SetFocus(bool isFocused)
{
    IsFocused = isFocused;
    FaceHoming.StartSeeking(
        isFocused ? Camera.main.transform.position + Vector3.forward * 2f : Vector3.zero,
        useLocalSpace: !isFocused
    );
    FaceTurning.StartSeeking(
        isFocused ? Camera.main.transform.rotation.eulerAngles.z : 0,
        useLocalSpace: !isFocused
    );
    FaceScaling.StartSeeking(
        isFocused ? 2f * Camera.main.orthographicSize / 4f : 1f,
        useLocalSpace: !isFocused
    );
    if (isFocused) OnCardFocused?.Invoke(this);  // 通知全局：我被聚焦了
}
```

聚焦模式会让卡牌：
- **飞到镜头前方**（Z 前移 2 单位）
- **正对镜头**（旋转到与相机一致）
- **放大**（根据相机 orthographicSize 动态计算）
- **排他聚焦**：通过静态事件 `OnCardFocused` 自动让其他卡的聚焦退出

## 6. CardGroup 交互响应

### 6.1 Trigger 碰撞检测

**源码**：[CardGroup.cs#L265-L309](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L265-L309)

`CardGroup` 通过物理触发器检测"拖拽中的卡牌是否进入了组的碰撞体"：

```csharp
void OnTriggerEnter2D(Collider2D col)
{
    var draggable = col.gameObject.GetComponent<DragOperator>();
    // 如果不是 Mount 类型且 Group 已满，则忽略
    if ((draggable == null || draggable.DragAction == DragAction.Mount) && !HasRoom())
        return;
    RespondToObjectCrossingBoundary(col, true);
}

void RespondToObjectCrossingBoundary(Collider2D col, bool isEntry)
{
    var thingBeingDragged = Dragging.Instance?.GetTarget();
    var dropParams = new DropParams
    {
        Source = cardComponent?.Group,
        Target = this,
        Card = cardComponent,
        DragType = dragHandler.DragAction
    };

    // 双方门控都通过才计数
    if (cardComponent != null && DragGates.AllUnlocked(dropParams)
        && dragHandler.GetComponent<DragDetector>().GroupDropGates.AllUnlocked(dropParams))
    {
        CollidersEntered += isEntry ? 1 : -1;
        SetAsActiveGroup(CollidersEntered > 0);
    }
}
```

**关键设计**：`CollidersEntered` 使用计数器（而非 bool），支持多个触发器嵌套区域的正确进出追踪。

### 6.2 HilightedGroup 静态栈

**源码**：[CardGroup.cs#L27-L55](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L27-L55)

```csharp
static List<CardGroup> GroupsHoveredWithObjects = new List<CardGroup>();

public static CardGroup HilightedGroup
{
    get
    {
        // 栈顶 = 最近进入的 Group
        return GroupsHoveredWithObjects.Count > 0 ? GroupsHoveredWithObjects[^1] : null;
    }
}

public static void AddHoveredGroup(CardGroup group)
{
    GroupsHoveredWithObjects.Remove(group);  // 去重
    GroupsHoveredWithObjects.Add(group);    // 加到栈顶
    OnNewActiveGroup?.Invoke(group);
}

public static void RemoveHoveredGroup(CardGroup group)
{
    GroupsHoveredWithObjects.Remove(group);
    if (GroupsHoveredWithObjects.Count > 0)
    {
        var newActiveGroup = GroupsHoveredWithObjects[^1];
        newActiveGroup.SetHilightState(true);
        OnNewActiveGroup?.Invoke(newActiveGroup);
    }
}
```

**工作原理**：

```
场景示例：卡牌拖入重叠的 Group A 和 Group B

  Group A  ─────┐
                │  Group B  ─────┐
  ┌─────────────┤                │
  │   ┌──────────┤────────────────┤
  │   │   卡牌   │                │
  │   └──────────┤                │
  └─────────────┤                │
                └────────────────┘

1. 卡牌进入 Group A → AddHoveredGroup(A)  → 栈 [A]          → Hilighted = A
2. 卡牌进入 Group B → AddHoveredGroup(B)  → 栈 [A, B]       → Hilighted = B
3. 卡牌离开 Group A → RemoveHoveredGroup(A) → 栈 [B]         → Hilighted = B
4. 卡牌离开 Group B → RemoveHoveredGroup(B) → 栈 []          → Hilighted = null
```

栈结构确保"最近进入的 Group"优先，解决了重叠区域的目标判定问题。

### 6.3 Drop 流程：合法性判定与挂载

**源码**：[CardGroup.cs#L110-L237](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L110-L237)

当 `Dragging.PostDrop` 触发时（鼠标松开后），`CardGroup.HandleDragDrop` 执行放下判定：

```
HandleDragDrop(DragDetector)
  │
  ├── 1. 检查 HilightedGroup == this ?
  │     └── 否 → 不处理（不是当前激活的 Group）
  │
  ├── 2. 构建 DropParams
  │     └── Source / Target / Card / DragType
  │
  ├── 3. 如果是 UseOnTargetAndDiscard
  │     └── GetClosestMountedCardIndex() → 找最近的目标卡
  │         └── 检查双方 TargetCardGates
  │
  ├── 4. 合法性校验（三重门控）
  │     ├── DropGates.AllUnlocked(dropParams)      ← 目标 Group 的门
  │     ├── GroupDropGates.AllUnlocked(dropParams) ← 源卡的门
  │     └── isTargetable（目标卡门控）
  │         └── 失败 → cardComponent.Group.ApplyStrategy() → 回原位
  │
  └── 5. 根据 DragAction 执行
      ├── Mount → Mount(card, insertPoint)
      ├── UseAndDiscard → 移到 Discard Group + 展示动画
      └── UseOnTargetAndDiscard → 移到 Discard + 触发 OnCardUsedOnTarget
```

### 6.4 MountingMode — 挂载位置策略

**源码**：[CardGroup.cs#L158-L175](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L158-L175)

```csharp
public enum MountingMode { Top, Bottom, Closest }

switch (Strategy.DragMountingMode)
{
    case MountingMode.Top:
        break;  // 不指定 index，自然追加到末尾
    case MountingMode.Bottom:
        insertPoint = 0;  // 插入到第一张
        break;
    case MountingMode.Closest:
        var closestIndex = GetClosestMountedCardIndex(dragDetector.transform.position);
        var diff = MountedCards[(int)closestIndex].transform.position - dragDetector.transform.position;
        insertPoint = diff.x > 0 ? closestIndex : closestIndex + 1;
        break;
}
```

**`MountingMode.Closest` 智能插入**：
- 找到距离鼠标最近的卡牌
- 根据鼠标在卡牌左侧还是右侧，决定插入位置
- 实现直觉的"插到两卡之间"体验
