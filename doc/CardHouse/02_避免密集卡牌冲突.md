## 1. 问题背景

在卡牌游戏中，以下场景会导致"密集卡牌选择冲突"：

```
场景 A：StackLayout 堆叠场景
┌─────────────────┐
│     卡牌5       │  ← 玩家想选这张
├─────────────────┤
│     卡牌4       │     但 Unity 物理中，
├─────────────────┤     只有最上面的 Collider
│     卡牌3       │     能收到鼠标事件
├─────────────────┤
│     卡牌2       │
├─────────────────┤
│     卡牌1       │
└─────────────────┘

场景 B：SplayLayout 手牌扇形
         ╱ 卡5 卡6 ╲
        ╱ 卡4 卡5 卡6 ╲   卡牌密集时中间的卡
       ╱ 卡3 卡4 卡5 卡6 ╲ 可能被相邻卡遮挡
      ──────────────────────
```

**核心矛盾**：Unity 3D 物理中，当多个 Collider 重叠时，`OnMouseDown` 只会被最前面（Z 值最小/最靠近摄像机）的 Collider 触发。

## 2. 机制一：OnlyTopActive 交互门控

**源码**：[CardGroupSettings.cs#L29-L37](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/Layouts/CardGroupSettings.cs#L29-L37)

```csharp
public enum GroupInteractability
{
    None,           // 所有卡都不可交互
    Active,         // 所有卡都可交互
    Inactive,       // 所有卡都不可交互（显式关闭）
    OnlyTopActive   // 仅最顶那张卡可交互
}

// CardGroupSettings.Apply() 中：
if (ForcedInteractability != GroupInteractability.None)
{
    var col = card.GetComponent<Collider2D>();
    if (col)
    {
        col.enabled = ForcedInteractability == GroupInteractability.Active
                      || ForcedInteractability == GroupInteractability.OnlyTopActive 
                         && i == cards.Count - 1;  // ← 关键：只有最后一张启用
    }
}
```

### 工作原理

```
StackLayout 堆叠时，Apply() 遍历所有卡：

  i=0  卡牌1 → col.enabled = false  ← 关闭碰撞
  i=1  卡牌2 → col.enabled = false
  i=2  卡牌3 → col.enabled = false
  i=3  卡牌4 → col.enabled = false
  i=4  卡牌5 → col.enabled = true   ← 只有最顶这张

结果：
  ┌───────────────┐
  │    卡牌5       │  ← Collider 启用
  ├───────────────┤
  │    卡牌4       │  ← Collider 禁用
  ├───────────────┤
  │    卡牌3       │  ← Collider 禁用
  ├───────────────┤
  │    卡牌2       │  ← Collider 禁用
  ├───────────────┤
  │    卡牌1       │  ← Collider 禁用
  └───────────────┘

鼠标点击时，物理系统只会检测到卡牌5的 Collider
→ OnMouseDown 只在卡牌5上触发
→ 从根源避免了选到中间卡的问题
```

### 何时切换交互性

当卡牌被拖拽走后，`CardGroup.Apply()` 被重新调用，此时 `MountedCards` 列表已更新，新的最后一张卡自动获得启用的 Collider。

## 3. 机制二：Z 轴分层避免 Z-fighting

**源码**：[SplayLayout.cs#L34-L37](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/Layouts/SplayLayout.cs#L34-L37)、[StackLayout.cs#L16-L17](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/Layouts/StackLayout.cs#L16-L17)

```csharp
// SplayLayout：
var newPos = transform.position
             + Vector3.back * (MountedCardAltitude + i * MarginalCardOffset)
             + ...

// StackLayout：
cards[i].Homing.StartSeeking(
    transform.position + Vector3.back * MountedCardAltitude + MarginalCardOffset * i, ...);
```

### Z 轴分层示意

```
Z 轴（从摄像机看向屏幕内部）

  Z=0.04  ┌─────────┐
          │  卡牌5   │  ← 在最前（最靠近摄像机）
  Z=0.03  ├─────────┤
          │  卡牌4   │
  Z=0.02  ├─────────┤
          │  卡牌3   │
  Z=0.01  ├─────────┤
          │  卡牌2   │
  Z=0.00  ├─────────┤
          │  卡牌1   │  ← 在最后
          └─────────┘

MountedCardAltitude = 0.01f（基础偏移）
MarginalCardOffset = 0.01f（每张卡的增量偏移）
```

### 解决的问题

- **Z-fighting**：两张卡 Z 值相同时的闪烁/穿插
- **渲染顺序**：Z 值大（靠前）的卡正确遮挡 Z 值小的（靠后）的卡
- **射线检测**：物理射线从摄像机发出，先击中 Z 值小的 Collider

## 4. 机制三：SplayLayout 扇形物理分离

**源码**：[SplayLayout.cs#L28-L47](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/Layouts/SplayLayout.cs#L28-L47)

```csharp
protected override void ApplySpacing(List<Card> cards, SeekerSetList seekerSets = null)
{
    var width = transform.lossyScale.x * (1f - ArcMargin);
    var spacing = width / (cards.Count + 1);  // 均匀间距
    for (var i = 0; i < cards.Count; i++)
    {
        var newPos = transform.position
                     + Vector3.back * (MountedCardAltitude + i * MarginalCardOffset)
                     + transform.right * width * -0.5f
                     + transform.right * (i + 1) * spacing;

        var newAngle = Mathf.Atan2(
            newPos.y - ArcCenterOffset.y,
            newPos.x - ArcCenterOffset.x
        ) * Mathf.Rad2Deg - 90;

        cards[i].Turning.StartSeeking(newAngle, seekerSet?.Turning);
    }
}
```

### 扇形布局计算示意

```
手牌场景（4 张卡）

  ArcCenterOffset
        │
        │  ← 弧形圆心
        │
        ▼
    ╱─────────────────────────────╲
   ╱                               ╲
  ╱    ┌───┐  ┌───┐  ┌───┐  ┌───┐  ╲
 ╱     │   │  │   │  │   │  │   │   ╲
╱      │ 1 │  │ 2 │  │ 3 │  │ 4 │    ╲
       └───┘  └───┘  └───┘  └───┘
        i=0    i=1    i=2    i=3

位置公式：
  X = groupX + (-0.5 * width) + (i+1) * spacing
  Z = -(Altitude + i * Offset)
  θ = atan2(card.y - arcCenter.y, card.x - arcCenter.x) - 90°

每张卡的 X 和 Z 都不同 → 物理上完全分离
```

### 不同卡片数的自适应

```
2 张卡：  ┌───┐  ┌───┐          间距 = width/3
          │ 1 │  │ 2 │
          └───┘  └───┘

3 张卡：  ┌───┐  ┌───┐  ┌───┐      间距 = width/4
          │ 1 │  │ 2 │  │ 3 │
          └───┘  └───┘  └───┘

6 张卡：  ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐       间距 = width/7
          │1││2││3││4││5││6│
          └─┘└─┘└─┘└─┘└─┘└─┘

公式：spacing = width / (cards.Count + 1)
→ 无论多少张卡，都均匀分布在 width 范围内
```

## 5. 机制四：拖拽时 Z 前移置顶

**源码**：[Dragging.cs#L66-L72](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Dragging/Dragging.cs#L66-L72)

```csharp
void Update()
{
    if (!IsDragging) return;
    GoToMouse(StartingZ - CardPopupDistance);
    // CardPopupDistance 默认 1f
}
```

### 工作原理

```
拖拽前：
  Z=0.04 ┌─────────┐
         │  卡牌5   │  ← 最顶
  Z=0.03 ├─────────┤
         │  卡牌4   │
  Z=0.02 ├─────────┤
         │  卡牌3   │  ← 被拖拽
  Z=0.01 ├─────────┤
         │  卡牌2   │
  Z=0.00 ├─────────┤
         │  卡牌1   │
         └─────────┘

拖拽中：
  Z=-0.98 ┌─────────┐
          │ 卡牌3   │  ← Z 前移 - CardPopupDistance = -0.98
  Z=0.04  ├─────────┤
          │  卡牌5   │
  Z=0.03  ├─────────┤
          │  卡牌4   │
  Z=0.01  ├─────────┤
          │  卡牌2   │
  Z=0.00  ├─────────┤
          │  卡牌1   │
          └─────────┘

卡牌3 的 Z 值最小 → 渲染在最前 → 不会被其他卡遮挡
```

`GoToMouse` 中的 Z 修正确保卡牌始终保持在拖拽 Z 平面，不受鼠标在屏幕上的实际深度影响。

## 6. 机制五：Collider 动态启用/禁用

**源码**：[CardGroupSettings.cs#L29-L37](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/Layouts/CardGroupSettings.cs#L29-L37) + [CardGroup.cs#L333-L341](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L333-L341)

`OnlyTopActive` 机制在 `Apply()` 时批量处理所有卡的 Collider 状态。除了堆叠场景外，这个机制也适用于：

- **Deck 牌堆**：只有最上面一张可抽
- **出牌区**：只有最前面的卡可点击
- **覆盖层**：前层元素遮挡后层交互

### 动态切换示例

```csharp
// 当卡牌从组中移除时：
public Card UnMount(int? index = null, ...)
{
    var card = Get(index);
    if (card != null)
    {
        MountedCards.Remove(card);
        card.Group = null;
        Strategy.Apply(MountedCards, ...);  // ← 重新 Apply
    }
}

// Apply 重新遍历：
// 卡牌5（原最顶）被移除后，卡牌4 变为最后一张
// i=3 → col.enabled = true  ← 现在卡牌4 可交互了
```

## 7. 机制六：MountingMode.Closest 最近插入

**源码**：[CardGroup.cs#L241-L257](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L241-L257) + [CardGroup.cs#L158-L175](file:///c:/Project/CardAnimationTestProject/Assets/CardHouse/CardHouseCore/Scripts/Groups/CardGroup.cs#L158-L175)

当卡牌被拖入一个已有多张卡的 Group 时，系统使用 `GetClosestMountedCardIndex` 决定插入位置：

```csharp
public int? GetClosestMountedCardIndex(Vector3 position)
{
    var closestDist = Mathf.Infinity;
    int? closestIndex = null;
    for (var i = 0; i < MountedCards.Count; i++)
    {
        var card = MountedCards[i];
        var diff = card.transform.position - position;
        var dist = diff.magnitude;
        if (dist < closestDist)
        {
            closestDist = dist;
            closestIndex = i;
        }
    }
    return closestIndex;
}
```

然后根据鼠标相对于最近卡的位置决定插入：

```csharp
case MountingMode.Closest:
    var closestIndex = GetClosestMountedCardIndex(dragDetector.transform.position);
    var diff = MountedCards[(int)closestIndex].transform.position - dragDetector.transform.position;
    insertPoint = diff.x > 0 ? closestIndex : closestIndex + 1;
    // diff.x > 0：鼠标在卡的左侧 → 插入到该卡位置
    // diff.x < 0：鼠标在卡的右侧 → 插入到该卡之后
    break;
```

### 插入位置示意

```
已有卡牌：[卡A] [卡B] [卡C]
                   ↑
              鼠标拖入这里

GetClosestMountedCardIndex → closestIndex = 1 (卡B最近)
diff = 卡B.position - mousePosition
diff.x < 0 → 鼠标在卡B右侧
insertPoint = closestIndex + 1 = 2

结果：[卡A] [卡B] [新卡] [卡C]
```

### 机制总结

| 机制 | 解决的问题 | 实现方式 |
|------|-----------|---------|
| **OnlyTopActive** | 堆叠中间卡无法选择 | `col.enabled = OnlyTopActive && isLast` |
| **Z 轴分层** | Z-fighting 闪烁 / 渲染顺序 | `Vector3.back * (Altitude + i * Offset)` |
| **SplayLayout** | 密集手牌遮挡 | 均匀 X 间距 + Z 分层 + 弧形旋转 |
| **拖拽 Z 前移** | 拖拽卡被遮挡 | `GoToMouse(StartingZ - CardPopupDistance)` |
| **Collider 动态切换** | 状态变化后交互性更新 | `Apply()` 重新遍历所有卡 |
| **Closest 插入** | 拖拽到卡组中间位置 | `GetClosestMountedCardIndex + 左右判定` |
